# History without Git

The person using Specwright may never open Git. The history they read is `history/story.md`. Each acceptance appends a paragraph in ordinary sentences: what they decided, what the agents had proposed when that differs, and the path of the page.

The project step creates a folder of those pages and the story. The screen and the CLI do not teach Git. The tool may keep a checkpoint so an open gate survives a restart. That checkpoint is not the history.

Session notes can be shortened later into a "story so far". The full story and the accepted pages stay. Forgetting a decision is not a feature of this product, because the reader has no Git log to restore it from.

Search is a box over the pages. It finds a chapter. It does not replace the paragraph. Full text is enough until an eval shows it missing something a person needed.

A lock that protects a database, hooks into other coding agents, mail between repositories, and a decay schedule are engines from other memory systems. They are not this history. [ADR 0004](../adr/0004-wiki-and-story.md) and [ADR 0005](../adr/0005-search-and-deferrals.md) record that split.
